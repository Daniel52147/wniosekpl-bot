Где Webhook в новом Stripe

Старое меню Developers → Webhooks часто спрятано. Сейчас так:

  1. Открой Workbench → Webhooks (Test mode)
  2. Или сверху справа Developers / иконка </> → вкладка Webhooks
  3. Кнопка Add destination / Create an event destination
  4. Events on your account → выбери события → тип: Webhook endpoint
  5. URL возьми из блока статуса ниже (.../api/billing/webhook)
  6. Signing secret → Reveal → вставь whsec_... в поле STRIPE_WEBHOOK_SECRET
